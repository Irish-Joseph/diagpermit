# Support

## How to get help

- **Bug reports / feature ideas:** open a GitHub issue.
- **Security problems:** see SECURITY.md — use private vulnerability
  reporting, not public issues.
- **Protocol discussions:** open a GitHub issue.

There is no commercial support tier in V0.1. The project is maintained by
volunteers in their personal time and sustained by community sponsorship
(see below).

## What to include in a bug report

- `diagpermit doctor` output.
- OS/architecture and how DiagPermit was installed.
- The exact commands run.
- For artifact problems: the output of `diagpermit verify <artifact>`.

## Sponsorship

Sponsorship funds sustainability: CI across Linux/Windows/macOS, release
infrastructure, dependency maintenance, conformance testing and security
review.

Illustrative goals:

- **$500/month** — supports Windows, macOS and Linux CI, release
  infrastructure and dependency maintenance.
- **$1,500/month** — supports regular security review, conformance testing
  and ecosystem adapters.

### What sponsors must NOT buy

Sponsors do not purchase: security-vulnerability priority, control over
security decisions, the ability to suppress vulnerabilities, guaranteed
roadmap control, protocol ownership, or maintainer voting power. Money
supports sustainability; it does not compromise project integrity.
